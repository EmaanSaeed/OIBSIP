# ☕ Coffee Haven - Landing Page

## 📌 About This Project
This is a **responsive landing page** for a coffee shop brand called **Coffee Haven**.  
I built this as my **Task 1** project during my **Web Development and Designing Internship** at **Oasis Infobyte**.

## 🛠️ Technologies Used
- **HTML5** (Structure)
- **CSS3** (Styling, Flexbox, Grid)
- **Google Fonts** (Typography)

## ✨ Features
- ✅ Fixed Navigation Bar with smooth links
- ✅ Hero Section with background image and Call-to-Action button
- ✅ Menu Section displaying coffee varieties
- ✅ About Section
- ✅ Responsive Design (works on mobile, tablet, and desktop)
- ✅ Consistent Color Palette (Coffee Theme)
