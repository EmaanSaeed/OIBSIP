# 🌡️ Temperature Converter Website

> A modern, interactive temperature conversion tool built with HTML, CSS, and JavaScript. Convert between Celsius, Fahrenheit, and Kelvin instantly — with a beautiful 3D thermometer interface.

---

## 📌 Project Overview

The **Temperature Converter Website** is a fully responsive web application that allows users to convert temperature values between three major units:

- **Celsius (°C)**
- **Fahrenheit (°F)**
- **Kelvin (K)**

With a sleek, dark-themed interface featuring a live thermometer visual, this project demonstrates core front-end development skills including real-time input handling, dynamic UI updates, and 3D transformations.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌡️ **Three-Way Conversion** | Convert between Celsius, Fahrenheit, and Kelvin instantly |

## 🚀 How to Use

1. **Enter a temperature** in any of the three input fields (°C, °F, or K).
2. The other two fields will **automatically update** with the converted values.
3. The **thermometer visual** will adjust to reflect the temperature.
4. The **mercury color** changes from cool blue to hot red as temperature rises.

---

## 🧪 Conversion Formulas

| From → To | Formula |
|-----------|---------|
| **C → F** | `(°C × 9/5) + 32 = °F` |
| **C → K** | `°C + 273.15 = K` |
| **F → C** | `(°F − 32) × 5/9 = °C` |
| **F → K** | `(°F − 32) × 5/9 + 273.15 = K` |
| **K → C** | `K − 273.15 = °C` |
| **K → F** | `(K − 273.15) × 9/5 + 32 = °F` |
