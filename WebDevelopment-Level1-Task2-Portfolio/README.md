# 💼 Emaan Saeed — Portfolio

> A modern, responsive personal portfolio website showcasing my skills, projects, education, and certifications. Built with HTML, CSS, and JavaScript.

---

## 📌 Project Overview

This is my **personal portfolio website** — a clean, modern, and fully responsive web page that represents who I am as a developer. It highlights my:

- 🎓 **Education** journey
- 💻 **Skills** and technologies I work with
- 📁 **Projects** I've built
- 🏆 **Certifications** I've earned
- 📬 **Contact** information

The design focuses on **visual appeal**, **user experience**, and **performance**, making it a complete representation of my professional identity.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🖼️ **Hero Section** | Full-screen background with animated liquid reveal effect |
| 🧭 **Navigation** | Smooth scrolling navbar with active section highlighting |
| 🎓 **Education Timeline** | Visual timeline showing my academic journey |
| 💻 **Skills Showcase** | Clean grid layout displaying my tech stack |
| 📁 **Projects Gallery** | Cards with project descriptions and GitHub links |
| 🏆 **Certifications** | List of Coursera certificates with direct links |
| 📬 **Contact Modal** | Interactive form for project inquiries |
| ⏰ **Live Clock** | Real-time local time display in header |
| 📱 **Responsive** | Fully optimized for all screen sizes |
| 🎨 **Dark/Light** | Clean aesthetic with subtle animations |
